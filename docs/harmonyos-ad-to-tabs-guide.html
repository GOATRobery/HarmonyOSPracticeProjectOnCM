在占位页已能切换的基础上

将内容拆成四个组件

完成前四步后，点击四个 Tab 已能展示对应文字和高亮，已经满足“可以是空页”的最小目标。这一步把占位内容拆成独立组件，方便以后分别填充真实页面。

你现有 HMHomePage 是带 NavDestination 的独立路由页面。把它改成下面这个普通内容组件，并导出；第 2 步中已将它从路由表移出。

06
继续使用现有的 ForEach 与自定义 Tab 栏

把内容组件接入对应 Tab

保留你原来的 Tabs、ForEach 和自定义标签样式。只将第 1 步放入 TabContent 的占位 Column 换成四个内容组件。

修改位置：HMMainPage.ets → ForEach 回调内 → TabContent
局部替换 · 四个 Tab 各自固定对应一个组件
TabContent() {
  if (index === 0) {
    HMHomePage()
  } else if (index === 1) {
    HMFindPage()
  } else if (index === 2) {
    HMMomentPage()
  } else {
    HMMinePage()
  }
}
.tabBar(this.tabBarBuilder(item, index))
.backgroundColor('#131215')
.expandSafeArea(
  [SafeAreaType.SYSTEM],
  [SafeAreaEdge.TOP, SafeAreaEdge.BOTTOM]
)

这里的 index 就是你现有 ForEach(this.tabBarData, (item: HMTabData, index: number) => { ... }) 回调参数。第 4 步补好的 .onChange 继续保留。

变量含义用途
index正在创建的这一项是第几个 Tab固定对应推荐、发现、动态、我的内容组件
currentIndex用户当前选中了哪个 Tab控制你已有的图标和文字高亮
内容判断使用每一项自己的 index。你当前代码和参考 Layout.ets 都使用了 this.currentIndex 判断每个 TabContent 的内容，这会使所有已构建内容页跟随当前选中项改变。此处用 index 让四个位置固定对应四个组件。

HMMainPageBuilder、HMTabData、tabBarData、tabBarBuilder、外层容器、背景、安全区、pathStack 和 onReady 均继续使用已有代码。
